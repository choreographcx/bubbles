Bubbles Pets Rescue Core

This plugin keeps rescue data separate from the website theme. It manages:
- Dogs and cats
- Pet statuses
- Structured adoption details
- Multiple breeds and personality tags
- Compatibility, training, home, and medical fields
- Reorderable image galleries
- Saved application records created by the Bubbles theme forms

Installation
1. Upload bubbles-pet-rescue-core.zip under Plugins > Add New > Upload Plugin.
2. Activate Bubbles Pets Rescue Core.
3. Install and activate the matching Bubbles Pets Rescue theme.
4. Manage pets from the Bubbles Rescue menu.

Existing Data
The plugin uses the same dog, cat, application, pet_status, and _bpr_* identifiers used by the earlier theme. Existing pets and applications are retained. Legacy breed, age, good-with, health, and application-link values remain supported.

Important
Deactivating or deleting the plugin does not delete pet or application records from the database.
